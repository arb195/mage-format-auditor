Image Format Auditor — راهنمای نصب و استفاده
=============================================

نصب (Chrome / Edge / Brave):
1. فایل zip را از حالت فشرده خارج کنید (یک پوشه به اسم image-auditor).
2. در مرورگر بروید به:  chrome://extensions   (در Edge:  edge://extensions)
3. گزینه Developer mode را روشن کنید (گوشه بالا سمت راست).
4. روی Load unpacked کلیک کنید و پوشه image-auditor را انتخاب کنید.
5. آیکون افزونه را از منوی پازل مرورگر Pin کنید.

استفاده:
- روی آیکون افزونه کلیک کنید؛ یک تب جدید باز می‌شود و آدرس سایتی که در آن بودید خودکار پر می‌شود.
- (یا هر آدرس دیگری را وارد کنید) و «شروع» را بزنید.
- تا پایان کار، تب ابزار را نبندید. می‌توانید «توقف موقت» یا «پایان» بزنید و نتایج تا همان لحظه باقی می‌ماند.
- خروجی CSV مستقیم در Excel باز می‌شود (فارسی هم درست نمایش داده می‌شود).

چه چیزهایی بررسی می‌شود:
- همه صفحات داخلی سایت (از طریق لینک‌ها + sitemap.xml)
- <img> و srcset و <picture>، تصاویر lazy-load (data-src و …)، پس‌زمینه‌های CSS (فایل‌های CSS، تگ style و style درون‌خطی)،
  og:image / twitter:image، فاوآیکن، poster ویدیو و لینک‌هایی که مستقیم به عکس اشاره می‌کنند.
- فرمت واقعی هر تصویر از روی پاسخ سرور تشخیص داده می‌شود (نه فقط پسوند)، پس اگر CDN به‌جای jpg، فایل webp تحویل دهد، اشتباه گزارش نمی‌شود.

نکته‌ها:
- فونت وزیرمتن داخل خود افزونه است (پوشه fonts) و به اینترنت نیاز ندارد.
- حالت شب/روز از دکمه بالای صفحه عوض می‌شود؛ «خودکار» از تنظیمات ویندوز پیروی می‌کند و انتخاب شما ذخیره می‌ماند.
- برای سایت‌های بزرگ، «حداکثر تعداد صفحات» را در تنظیمات تغییر دهید (پیش‌فرض ۵۰۰۰).
- اگر سایت محدودیت درخواست یا فایروال (مثل ابرآروان/کلودفلر) دارد، «درخواست هم‌زمان» را کم کنید (۱ یا ۲) و کمی «مکث» بگذارید.
- چون درخواست‌ها با کوکی‌های مرورگر خودتان ارسال می‌شوند، اگر سایت چالش امنیتی دارد، یک بار سایت را در همان مرورگر باز کنید و بعد ابزار را اجرا کنید.
- تصاویری که فقط با جاوااسکریپت (بعد از بارگذاری صفحه) ساخته می‌شوند در HTML اولیه نیستند و ممکن است دیده نشوند.
